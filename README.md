# Task_3 — UI-тесты Stellar Burgers

Java 11, Maven, JUnit 5, Selenium, RestAssured, Allure.

Проверяются регистрация (включая границу в шесть символов), четыре способа входа,
личный кабинет, возврат через меню и логотип, выход и три раздела конструктора.
Page Object находятся в пакете `praktikum.pages`: отдельный класс для каждой страницы.
У каждого теста новый браузер; существующие пользователи создаются через API и удаляются после теста.
В тесте регистрации пользователь создаётся через интерфейс. При ошибке прикладывается скриншот.
Взаимодействия и проверки страниц отмечены `@Step`. Используются явные ожидания.

Google Chrome (драйвер подбирается Selenium Manager):
```shell
mvn clean test -Dbrowser=chrome
```

Яндекс.Браузер: установите браузер и скачайте соответствующий его версии YandexDriver
из https://github.com/yandex/YandexDriver/releases.
```shell
mvn clean test -Dbrowser=yandex -Dyandex.binary="C:/path/to/browser.exe" -Dyandex.driver="C:/path/to/yandexdriver.exe"
```

По умолчанию используется режим без окна. Чтобы видеть браузер, добавьте `-Dheadless=false`.
Для Chrome с нестандартным путём есть `-Dchrome.binary=...`, для другого стенда — `-DbaseUrl=...`.

```shell
mvn allure:report
mvn allure:serve
```

Результаты: `target/allure-results`. HTML-отчёт: `target/site/allure-maven-plugin/index.html`.
Сохранённые результаты и отчёты по браузерам находятся в `reports/chrome/` и `reports/yandex/`.
Файлы `allure-report/index.html` в этих каталогах открываются двойным щелчком без сервера.
Фактический прогон Chrome: 7 проверок прошли, 7 остановились на сетевых ошибках.
В Яндекс.Браузере выполнены три проверки разделов конструктора; все остановились на сетевых ошибках,
остальные 11 ещё не запускались. Перед сдачей нужен полный прогон в обоих браузерах без VPN.
Для накопления результатов двух браузеров используйте `mvn clean test` для первого,
а затем `mvn test` для второго, без повторного `clean`; браузер записывается в параметры Allure.
